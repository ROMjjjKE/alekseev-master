# Алексеев В. С. — мастер на все руки, Слуцк

Сантехника, электрика, мелкий ремонт, сборка мебели. Один выезд — весь список дел.
Телефон +375 44 718-57-40.

**Живой сайт:** https://romjjjke.github.io/alekseev-master/

## Что внутри

- Герой с циклической фразой «обычно в списке»: течёт под мойкой → искрит розетка → карниз висит
  криво → шкаф не собран. Четыре варианта лежат в одной ячейке grid, поэтому подмена не двигает вёрстку.
- Указатель из 32 фраз клиентским языком, сгруппированных по глаголу, а не по виду услуг.
- Пин-сцена «листы»: четыре категории работ въезжают одна на другую и укладываются стопкой со
  смещением 3,2% на уровень, справа счётчик листа и подпись. На мобильном стопка становится
  обычным списком карточек.
- Инструмент и расходники, четыре шага визита, FAQ на `<details>`, форма со списком дел в WhatsApp.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для стопки), Lenis.
Шрифты самохостингом: Play 400/700 + Mulish 400/600, 73 KB на 8 файлов, метрические фолбэки
(`size-adjust` 98,1% и 104,3%). Изображений нет: типографика, линии и зерно.
